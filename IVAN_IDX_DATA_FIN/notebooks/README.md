# IDX Stock Big Data Project

This project demonstrates an end-to-end data pipeline for Indonesian Stock Exchange (IDX) stock data using Python and PostgreSQL.

## Project Structure
- notebooks/
  - 01_db_connection.ipynb
  - 02_idx_api_ingestion.ipynb
  - 03_data_cleaning.ipynb
  - 05_sql_analysis.ipynb
  - 06_visualization.ipynb

## Workflow
1. Establish connection to PostgreSQL database
2. Fetch IDX stock data from public API
3. Clean and validate the dataset
4. Store cleaned data into database
5. Perform SQL-based analysis
6. Visualize key stock insights

## Technologies Used
- Python
- Pandas
- PostgreSQL
- SQLAlchemy
- Matplotlib
